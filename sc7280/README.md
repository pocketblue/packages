# Packages for Qualcomm SC7280/QCM6490 devices

Support for devices based on the Qualcomm SC7280 (Snapdragon 7c Gen 3) and
QCM6490 SoCs, such as the Nothing Phone (1) (nothing-spacewar) and the
Fairphone 5.

These rpm specs are based on postmarketOS packages.

Special thanks to @JIaxyga

The kernel for these devices is built as an ARK-style kernel directly from the
sc7280-mainline kernel tree and is not spec'ed in this repository.
